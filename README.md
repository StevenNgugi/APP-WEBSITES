# APP-WEBSITES

This repository includes the source for **ShoalFlow AI**, an AI-assisted business operations website and web app.

- [ShoalFlow AI source](./shoalflow-ai/)
- [Live website and web app](https://shoalflow-ai-cdxrty.v2.appdeploy.ai/)

The live service is hosted on AppDeploy. **GitHub commits do not automatically deploy to AppDeploy**; a separate CI/CD integration must be configured to enable that behavior.

## ShoalFlow AI

Frontend: React, Vite and TypeScript. Backend: AppDeploy SDK and database with authentication and AI drafting.

Project code is a snapshot synchronized from AppDeploy, which remains the current deployed-source authority. To develop locally, platform-provided SDK tooling and deployment configuration may be required.

Do not commit access tokens, credentials, or customer data.
